# Data

Esta carpeta contiene los datos ficticios utilizados para demostrar el funcionamiento del workflow.

## Archivo

`cartera_demo.xlsx`

El dataset contiene información simulada de cuentas vencidas y se utiliza como fuente de datos para el workflow de n8n.

Las principales variables utilizadas incluyen:

- `id_factura`
- `cliente`
- `correo`
- `telefono`
- `ciudad`
- `servicio`
- `monto`
- `fecha_emision`
- `fecha_vencimiento`
- `dias_vencido`
- `estado`
- `intentos`
- `ultima_gestion`
- `nivel_riesgo`
- `justificacion`

Los campos `nivel_riesgo` y `justificacion` son utilizados para almacenar el resultado generado por la inteligencia artificial.

> **Nota:** Todos los datos incluidos en este repositorio son ficticios y están destinados exclusivamente a fines demostrativos.
